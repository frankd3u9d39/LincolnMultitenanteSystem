# GROUP 1: Student Module

## Ownership
- **Assigned Group**: GROUP 1
- **Scope**: Dedicated feature logic, components, hooks, services, types, and utils for Student users.

## Directory Structure
```text
frontend/modules/student/
├── components/   # Student-specific UI widgets
├── hooks/        # Student-specific custom React hooks
├── services/     # Student-specific API integration services
├── types/        # Student domain TypeScript models/interfaces
├── utils/        # Student domain calculations & formatters
└── README.md
```

## Rules
1. Group GROUP 1 works primarily inside this directory.
2. Do NOT import directly into other module folders.
3. Consume shared UI elements from `frontend/components/`.
4. Route compositions are located under `frontend/app/(student)/`.
